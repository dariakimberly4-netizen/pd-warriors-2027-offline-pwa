# PD Warriors 2027 Offline PWA
Installable GitHub Pages attendee and QR system. Import Excel, search by first/last name, select attendee, generate QR, and record local snack/lunch/raffle claims. Participant raffle only. Data is stored in the browser on the device.

For offline use: open the deployed site online once, then Add to Home Screen / Install App. Test airplane mode before the event. Separate devices do not automatically sync offline data.
